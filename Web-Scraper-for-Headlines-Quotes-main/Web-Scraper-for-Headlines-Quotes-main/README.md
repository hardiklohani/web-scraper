Web Scraper for Quotes 📝

A Python-based web scraping project that extracts quotes, author names, and tags from a public website using Requests and BeautifulSoup. The extracted information is cleaned and saved in JSON format.

🚀 Features
Fetch webpage content using HTTP requests.
Extract quotes using BeautifulSoup.
Collect author names and related tags.
Scrape multiple pages automatically.
Handle HTTP errors and missing HTML elements.
Save extracted information in JSON format.
Add a delay between requests for responsible scraping.

🛠️ Technologies Used

Python 3
Requests
BeautifulSoup4
JSON
Time
Pathlib

🌐 Source Website

Quotes to Scrape: https://quotes.toscrape.com/
This website was selected because it is publicly accessible and designed for practising web scraping. The project extracts publicly displayed quotes, authors, and tags without accessing login-protected pages or personal information.
